# 前期「先把活全干了」应急方案（AI 代替未到位成员先行实现）

## 背景

负责人决定：在队友到位前，由 AI（湛卢 IDE + 负责人监督）先把 A/B/D 的活按各自任务书先做出来，放在**独立的临时集成分支**上，等各成员认领后按模块拆还给他们（cherry-pick 或直接在其个人分支 rebase），避免阻塞进度。

## 规则（防止失控）

1. 所有应急产出放在一个分支：`feat/d-advance-baseline`，**绝不直接合入 main**；
2. 每个模块的实现严格遵守对应 Wave 任务书（04/06/07/08 号文件），代码里用模块内 README 标注"AI 预生成，待成员 X 认领与重写"；
3. 应急分支上禁止改 contracts/（契约仍以 Wave 0 流程为准）；
4. 成员认领后的交接方式：`git checkout feat/a-equipment-monitoring && git merge feat/d-advance-baseline --no-ff` 只取自己目录，或让 IDE 按任务书重新生成（推荐，同时给该成员留下自己的湛卢使用记录）。

## 执行顺序（对应负责人操作）

```bash
git switch main && git pull --ff-only
git switch -c feat/d-advance-baseline
# 按 A -> B -> D 顺序执行各任务书的 IDE 提示词，每完成一个模块：
python scripts/check_repo.py --strict
git add apps/<模块> && git commit -m "feat(a): AI预生成设备监测模块骨架"   # 注意 scope 用模块字母
git push -u origin feat/d-advance-baseline
```

## 给湛卢 IDE 的总控提示词（粘贴即用）

```
你是本仓库的前期开发代理。仓库是四人微服务项目（设备监测A/预警B/工单C/集成D），契约在 contracts/（v1.1.0，只读，禁止修改）。

任务：在当前分支上按以下顺序实现三个模块，每个模块完成后停下，输出改动文件清单等待我确认再继续：

1) apps/equipment-monitoring（端口 8101）：
   - GET /api/v1/equipment/{equipmentId}（C-INT-01，对照 contracts/openapi.yaml 实现，含 404/500 ErrorResponse）
   - POST /api/v1/equipment-status-events（C-INT-03，EventId 幂等，设备状态用 contracts/shared-enums.json 的 equipmentStatus）
   - SQLite 存储 + 3 台设备种子数据 + pytest 测试 + README 启动说明

2) apps/fault-warning（端口 8102）：
   - 风险评估模拟器（输入指标 → LOW/MEDIUM/HIGH/CRITICAL，映射 P1-P4）
   - WarningRaised 事件发送（报文必须能过 contracts/schemas/warning-raised.payload.schema.json 校验，样例对照 contracts/examples/warning-raised.json）
   - POST /api/v1/maintenance-conclusions 接收端（C-INT-04，EventId 幂等）
   - pytest 测试 + README

3) apps/integration-quality（端口 8104）：
   - GET /api/v1/users/{userId}/access-context（C-INT-05，对照 openapi.yaml 的 UserAccessContext）
   - 4 个角色种子数据 + pytest 测试 + README

技术栈统一：Python 3.12 + FastAPI + pydantic v2 + SQLite。时间一律 RFC 3339 UTC。跨服务地址用环境变量（.env.example 已有定义）。每个模块的对外接口行为以 contracts/openapi.yaml 为唯一标准，实现完成后用 contracts/examples/ 的示例报文写契约测试。

禁止：修改 contracts/、apps/maintenance/（成员C已有实现）、.github/、scripts/、docs/ 任何文件。

每个模块完成后输出：新增/修改文件清单 + 运行 pytest 的结果 + 与契约逐条对照的自检表。
```
