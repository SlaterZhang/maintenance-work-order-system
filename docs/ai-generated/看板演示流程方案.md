## 三、完整演示剧本（建议演示顺序）

### 【第 0 幕】登录与会话建立
1. 打开看板 `http://localhost:8080/dashboard.html`
2. 点击"主管 USER-D-001"快捷按钮 → 自动填充账号密码
3. 点击"登录" → 系统调用 D 服务 `/api/v1/auth/login`
4. 返回 JWT Token + 用户权限集（ADMIN_ALL / 各角色细分权限）
5. 看板加载：设备列表（3 台）+ 统计卡片 + 今日预警

### 【第 1 幕】设备健康总览（A 服务）
1. 看板展示 3 台设备：
   - EQ-000001 一号数控机床（LINE-01 · 运行中）
   - EQ-000002 二号加工中心（LINE-01 · 运行中）
   - EQ-000003 三号冷镦机（LINE-02 · 试运行）
2. 统计卡片：设备总数 / 正常运转 / 预警中 / 维修中
3. 信号灯颜色：绿=正常，黄=预警，红=故障

### 【第 2 幕】点击设备查看详情（A + B 联动）
1. 点击 EQ-000003 → 进入设备详情页
2. 加载三张趋势图：温度 ℃ / 振动 mm·s⁻¹ / 电流 A
3. 显示设备当前状态 + 健康度 + 风险等级
4. 显示系统判断（来自 B 服务最近一次评估）

### 【第 3 幕】注入异常触发全链路（核心演示）⭐
1. 点击"⚠ 注入异常（严重）"
2. **链路 1**：POST A `/api/v1/equipment/EQ-000003/telemetry`
   - 注入样本：温度 95℃ / 振动 15.8 mm·s⁻¹ / 电流 52A（严重超标）
   - 返回 202 Accepted
3. **链路 2**：POST B `/api/v1/health-evaluations`
   - B 服务评分：healthScore=30.6，riskLevel=CRITICAL
   - B 自动生成预警：WARN-20261004-xxxx
   - 返回 200 OK
4. **链路 3**：B → C 异步事件（WarningRaised）
   - B 通过事件队列投递 WarningRaised 事件
   - C 服务消费事件，自动创建维修工单
5. **链路 4**：等待 2.5 秒后刷新
   - 看板设备列表：EQ-000003 变为红灯
   - 今日预警：新增 CRITICAL 预警
   - 维修工单页：新增 WO-xxx（P1 优先级，待确认）
6. 操作日志面板：逐步显示每步调用的结果

### 【第 4 幕】工单处置流转（C 服务）
1. 切换到"维修工单"页
2. 点击工单行 → 展开操作面板
3. 主管操作：**确认** → 状态 待确认 → 待派单
4. 主管操作：**派单** → 选择维修工程师 → 状态 待派单 → 维修中
5. 工程师操作：**提交验收** → 填写根因/措施/结果 → 状态 → 待验收
6. 验收员操作：**通过验收** → 状态 → 已完成
7. 或验收员操作：**驳回** → 状态 → 维修中（返工）

### 【第 5 幕】恢复验证（闭环）
1. 返回设备详情页
2. 点击"✓ 恢复正常数据"
3. 注入正常样本：温度 62℃ / 振动 2.1 mm·s⁻¹ / 电流 28A
4. B 服务评估：healthScore=95，riskLevel=LOW
5. 图表趋势回升，设备状态恢复绿灯
6. 演示闭环完成

## 五、关键技术要点

### 5.1 认证与头部要求
| 服务 | 端点 | 必需头部 |
|------|------|----------|
| A | POST /telemetry | X-Internal-Token, X-Trace-Id, Idempotency-Key |
| B | POST /health-evaluations | X-Internal-Token, X-Trace-Id, Idempotency-Key |
| B | GET /warnings | Authorization, X-User-Id |
| C | GET /work-orders | Authorization, X-User-Id |
| C | POST /work-orders/{id}/actions | Authorization, X-User-Id |
| D | POST /auth/login | Content-Type |

### 5.2 已修复的关键 Bug
1. **X-User-Id 缺失**（commit 09aa41c）
   - 症状：看板预警数据为空（401）
   - 修复：api() 函数统一注入 X-User-Id

2. **B 服务 CORS 缺失**（commit 0e80781）
   - 症状：浏览器请求 B 服务被拦截
   - 修复：main.py 添加 CORSMiddleware

3. **X-Trace-Id 缺失**（commit 868977f）
   - 症状：注入链路失败
   - 修复：internalHeaders() 添加 X-Trace-Id

### 5.3 数据契约字段对照（易错点）
| 前端旧写法 | 后端契约字段 |
|-----------|-------------|
| temperature | temperatureC |
| vibration | vibrationMmS |
| current | currentA |
| （缺失） | sampleId (UUID) |
| （缺失） | measuredAt (ISO8601) |
